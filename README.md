# Panique — le bouton rouge

Une expérience interactive créée pour Inktober 2026, autour du mot « Panique ».

Appuyez sur le bouton rouge pour déclencher l'un des 17 scénarios aléatoires : écran fissuré, fenêtres absurdes, fausses notifications, compte à rebours… ou absolument rien.

Tous les effets restent dans la page et n'ont aucun impact sur l'appareil.

## Utilisation

Téléchargez le dépôt et ouvrez `index.html` dans un navigateur récent. Aucune installation, dépendance externe ou compilation n'est nécessaire.

- Cliquez sur **PANIQUE**, ou utilisez Entrée/Espace lorsque le bouton a le focus.
- Appuyez sur **Échap** ou sur le bouton de remise à zéro pour réinitialiser la page.
- Activez le son avec le contrôle dédié, si vous le souhaitez. Cette préférence est conservée localement lorsque le navigateur le permet.

L'interface est en français, s'adapte au mobile et tient compte de la préférence de mouvement réduit.
